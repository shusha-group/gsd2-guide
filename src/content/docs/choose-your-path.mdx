GSD is the same tool for everyone, but the fastest way to get productive depends on where you're coming from. Pick the path that best describes you and read the pages in order.

Not sure which path fits? Start with [Is GSD Right for Me?](../is-gsd-right-for-me/) — it'll route you here with a recommendation.

---

## Path 1 — Solo Business Builder

**You're building a product, not a career in software.** You may have some coding background, or you may be working almost entirely through AI. You care about shipping reliably without getting lost in tooling.

If you're migrating from a visual builder, [Coming from Replit](../coming-from-replit/) or [Coming from Lovable](../coming-from-lovable/) covers the differences and what to expect.

- [ ] [Why GSD 2](../solo-guide/why-gsd/) — understand the problem GSD solves before committing to it
- [ ] [Is GSD Right for Me?](../is-gsd-right-for-me/) — confirm GSD fits your situation
- [ ] [Getting Started](../getting-started/) — install GSD and run your first session
- [ ] [The Solo Guide](../solo-guide/) — end-to-end walkthrough of a real milestone from requirements to shipped code
- [ ] [Your First Project](../solo-guide/first-project/) — put the workflow into practice on something real
- [ ] [Controlling Costs](../solo-guide/controlling-costs/) — keep API spend predictable as you build
- [ ] [Quick Reference](../quick-reference/) — the 15 commands you'll actually use

Once you're comfortable with the basics:

- [ ] [Building Rhythm](../solo-guide/building-rhythm/) — how to structure daily work for sustained momentum
- [ ] [When Things Go Wrong](../solo-guide/when-things-go-wrong/) — how GSD recovers from failures and blockers
