---
title: "/gsd changelog"
description: "View categorised release notes for GSD, filtered by version."
---

Displays GSD release notes, organised by category (features, fixes, improvements). Useful for checking what changed in a specific version or reviewing recent updates after upgrading.

## Usage

```
/gsd changelog
/gsd changelog <version>
```

Without arguments, shows the most recent release. Pass a version number to view notes for a specific release.

## What It Shows

Release notes are grouped into categories — new features, bug fixes, performance improvements, and breaking changes. Each entry includes a brief description of what changed.

## Related Commands

- [`/gsd history`](../history/) — view execution history rather than release history
- [`/gsd update`](../update/) — check for and apply GSD updates
