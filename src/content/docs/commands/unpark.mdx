---
title: "/gsd unpark"
description: "Reactivate a parked milestone, making it available for auto-mode dispatch again."
---

Reactivates a milestone that was previously parked with `/gsd park`. The milestone becomes eligible for auto-mode dispatch again.

## Usage

```
/gsd unpark
/gsd unpark <milestone-id>
```

Without an ID:

- If **one milestone** is parked, it's unparked automatically
- If **multiple milestones** are parked, GSD lists them and asks you to specify which one

## Related Commands

- [`/gsd park`](../park/) — park a milestone to exclude it from dispatch
- [`/gsd queue`](../queue/) — view the full milestone queue including parked milestones
