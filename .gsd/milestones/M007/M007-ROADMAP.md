# M007: Guide Consolidation & Usability

## Vision
Consolidate the gsd2-guide into a self-sufficient documentation hub for solo builders. Add a scannable changelog summary layer, GitHub issue auto-linking, a curated quick-reference command page, cross-referenced official docs content, decision/brief-writing/cost guides, and navigation polish.

## Slice Overview
| ID | Slice | Risk | Depends | Done | After this |
|----|-------|------|---------|------|------------|
| S01 | Quick Reference + Decision Guide | low | — | ✅ | After this: new users can find the 15 most-used commands on one curated page and assess whether GSD suits their project in 30 seconds. |
| S02 | Changelog Improvements | medium | — | ✅ | After this: every release has a solo-builder-perspective summary on a highlights page; every #NNN is a clickable GitHub link in the full changelog. |
| S03 | Content Consolidation | medium | — | ⬜ | After this: auto mode breakdown, .gsd/ directory structure, verification ladder, and v1→v2 comparison are integrated into existing guide pages in the guide's own voice. |
